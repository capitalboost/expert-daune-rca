Solicitările sunt accesibile persoanelor autorizate din cadrul firmei și furnizorilor tehnici implicați în găzduirea website-ului și livrarea corespondenței, în măsura necesară funcționării acestor servicii. Nu vindem datele de contact. Putem comunica informații autorităților când avem o obligație legală sau când este necesar pentru constatarea, exercitarea ori apărarea unui drept.

4. Cât păstrăm datele

Păstrăm solicitarea și corespondența cât este necesar pentru răspuns și soluționare. Dacă rezultă o relație contractuală, se aplică perioadele de păstrare aferente documentelor și obligațiilor respective. Păstrarea ulterioară este limitată la ceea ce este necesar pentru obligații legale ori apărarea drepturilor; solicitările care nu mai sunt necesare sunt șterse.
